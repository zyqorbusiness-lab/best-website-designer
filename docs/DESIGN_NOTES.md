# Design notes

The Lab is a set of design studies. Each concept takes one interaction pattern that top product sites and design reels use today and builds it as a complete, original mini site for a fictional brand. The patterns studied:

| Pattern family | What it is | Where to see it |
|---|---|---|
| A. Colourway morph | The product changes colourway and the background, type and UI follow in one eased move. | Stride Aero, VOLT, Worlds 01 |
| B. Giant type behind the product | A huge word sits behind the hero object; product and type move as layers. | Meridian, Volta, VOLT, Worlds 02 |
| C. Travelling hero object | One object stays on screen and moves between sections as the story changes around it. | Meridian, Ember & Oak |
| D. Reveal transitions | Paper tear, organic masks, wipes from the control you pressed. | Ember & Oak, Verdant, every mode switch |
| E. Orbit and radial layouts | Circular carousels, card fans that bloom around a headline. | Umami Ring, Signal Studio, Worlds 04 |
| F. Callouts and exploded views | Leader lines that track 3D points; products that come apart into parts. | Hush One, Stride Aero, Worlds 03 |
| G. Kinetic type | Letters that roll, slam, strike on or fill on scroll. | VOLT, Hush One, Signal Studio |
| H. Environment storytelling | The product placed in a world: clouds, a room, a studio floor at night. | Dew Theory, Nook, Volta |
| I. Micro-interactions | Magnetic pills, cursor labels, odometer numbers, swatch ripples, numbered dots. | Everywhere |
| J. Case-study format | Browser-card mockups, numbered slides, before/after. | Stride Aero, Work section |
| K. Physics and 3D scroll | Draggable physics objects, scroll-scrubbed 3D spins, horizontal tracks. | Signal Studio, Volta, Hush One |

Every concept also has one visitor-controlled MODE that transforms the whole page (Night run, Lume, ANC quiet, roast level, Sunlit/Dusk, AM/PM, Charged, spice level, Calm/Loud, Day/Night, collection colour), and a separate phone page designed for touch.

House rules the code follows: one three-colour palette per site, no emoji (inline SVG icons only), no AI-generated imagery, no fake clients or reviews, `prefers-reduced-motion` respected, zero console errors at 1440x900 and 390x844.
