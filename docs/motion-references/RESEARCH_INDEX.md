## The 5 most useful techniques overall
1. Never cut, glide (ref 1, soft-3D pins): one continuous world, the camera glides 20–40 % of width in 0.8–1.2 s while objects pop 0→110→100 % in 9 frames, then float. Blender softworld.py + DOF f/2.
2. Move fast, hold long (ref 5, glossy cards pins): 0.4 s ease-out move then ~1 s hold where only a light sweep travels across the card. Reads premium; cheap to render.
3. Chrome type seen straight-on (ref 2): extrude + chiselled bevel, metallic 1 / roughness 0.1, studio HDRI, glow added in compositing; never shoot small type from above.
4. One event per beat, one sfx per event (refs 3, 4): ~2 events/s for the hyper style, 1 per 1–2 s for the premium style; whoosh starts 3–5 frames before a cut, hit on the frame; the raw card in a before/after stays dry.
5. Two typefaces + one colour system (kinetic type pins, refs 1–3): heavy grotesk lines, 1 italic-serif emphasis word at 1.5–2.5×, max 3 colours; words land on audio onsets ±2 frames.
