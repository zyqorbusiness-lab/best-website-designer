Five weights

One block, five cuts.

Each cut is the same file at a different weight. The stone Q above can be cut at any of them.

  1. 100Quarry ThinThin
  2. 300Quarry LightLight
  3. 400Quarry RegularRegular
  4. 700Quarry BoldBold
  5. 1000Quarry BlackBlack

What is in the file

Four axes, one font file.

wght
100 to 1000Weight, the axis the magnet pours in.
wdth
25 to 151Width, spent to keep each line the same length.
GRAD
−200 to 150Grade: darker strokes with no change in width.
opsz
8 to 144Optical size: display cuts up top, text cuts in this paragraph.

Quarry is a fictional foundry. The typeface on this page is Roboto Flex by the Roboto Flex Project Authors, free under the SIL Open Font License, subset here to 139 KB with those four axes live.
