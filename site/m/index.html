(02) Components

Fourteen pieces, in detail.

Reusable interface pieces studied from award-winning sites and rebuilt from scratch: each one has a live preview that works the same on a phone and a laptop, keyboard and touch support, and a reduced-motion mode. Free to use, MIT.

Plain HTML, CSS and JavaScript. No framework, no build step.

Component 01

Scroll-scrubbed 3D stage

Real CC0 scan + HDRI; camera and model move through chapter keyframes with scroll; lazy, poster fallback.
Component 02

Magnetic button

Leans toward the pointer, fills from the entry point, rolls its label; tap ripple on phones.
Component 03

Split text reveal

Line-mask rise, letter flip and scroll-scrub reading highlight; re-measures lines, screen-reader safe.
Component 04

Liquid glass card

Edge refraction via SVG displacement (Chromium), blur fallback, specular highlight, tilt, draggable.
Component 05

Sticky storytelling

Pinned media with chapter wipes, progress line, numbered rail; same on phone.
Component 06

Marquee

Seamless loop, speeds up with scroll velocity, flips with scroll direction, drag with inertia.
Component 07

Cursor follower

Dot + lagging ring, label over work, sticky ring on links, hides over inputs, off on touch.
Component 08

Image trail and hover reveal

Pointer image trail and a hover-reveal project list that turns into a tap accordion on phones.
Component 09

Preloader

Counts real bytes of the model/HDRI/images, never flashes on cached loads, panel-wipe exit.
Component 10

Page transition

Circle reveal from the click point between pages (native View Transitions + fallback) and for a theme switch.
Component 11

Pricing switcher

Zyqor's real $300 / $1k / $10k tiers: squish pill, odometer price, ARIA tabs.
Component 12

Quote carousel

Native scroll-snap swipe, mouse drag with inertia, accessible autoplay with Pause; real quotes, no fake reviews.
Component 13

Mega menu

Desktop mega panels with hover intent + keyboard; phone full-screen accordion sheet with focus trap.
Component 14

Footer with wordmark

Giant per-letter rising wordmark, Gmail-on-desktop / mailto-on-phone, copy email, local time, legal links.

(04) About

One person. Start to finish.

I'm Sujon Hoque. Zyqor Studio is me: a self-taught web designer and developer in West Bengal, India.

I design and build every project myself, from the first layout to the live link: websites, browser games and Android apps. No templates, no page builders: I write the code, so the page does exactly what it should and loads fast on an ordinary phone.
