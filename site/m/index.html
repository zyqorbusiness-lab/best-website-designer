(04) About

One person. Start to finish.

I'm Sujon Hoque. Zyqor Studio is me: a self-taught web designer and developer in West Bengal, India.

I design and build every project myself, from the first layout to the live link: websites, browser games and Android apps. No templates, no page builders: I write the code, so the page does exactly what it should and loads fast on an ordinary phone.

“A good website doesn’t ask people to work hard to understand it.”Sujon, on how he works
