# Humdinger (concept by Zyqor Studio): credits

Humdinger is a fictional brand. This page is a concept by Zyqor Studio (Sujon Hoque).

- 3D device (H-1): built in code with three.js geometry (RoundedBoxGeometry, LatheGeometry, TubeGeometry, instanced pads); textures drawn in code on canvas. Our own work, MIT. No downloaded model.
- Sound: every sound is synthesised live with the Web Audio API in js/sound.js. No audio files.
- Line scenes (bus, desk, field) and the jeans pocket: SVG drawn in code. Our own work, MIT.
- Stills (stills/*.webp, WebGL-off fallback) and og.jpg: rendered or screenshotted from this page's own real-time scene. Our own work, MIT.
- Fonts (self-hosted, SIL Open Font License 1.1): Bricolage Grotesque by Mathieu Triay; DM Sans by Colophon Foundry; JetBrains Mono by JetBrains. See fonts/OFL.txt.
- Libraries (vendored in /vendor): three.js (MIT) incl. RoomEnvironment for reflections; Lenis (MIT) for smooth scrolling.

No photos, no video, no generated imagery, no Fontshare fonts, no Mixkit assets.
