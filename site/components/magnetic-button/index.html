Magnetic button

Move the pointer near a button: it leans toward you before you touch it. The colour fills from the exact point you enter and drains out where you leave. On a phone, tap: the press and the ripple start under your finger.

Use it

Copy the folder magnetic-button/ (the .js and .css files) into your project. No build step and no framework.

Behaviour

  • Pull, label roll and arrow turn run only on a mouse or trackpad (hover:hover and pointer:fine).
  • Touch: a short press (scale .96) and a fill ripple from the tap point; nothing depends on hover.
  • Keyboard: :focus-visible shows the fill and the rolled label, so focus is as visible as hover.
  • prefers-reduced-motion: no movement at all, the fill appears without animation.
  • The duplicate label is aria-hidden, so screen readers read the text once.
  • One rAF spring per button, and it stops when the button is at rest (no idle loop).

Credits

  • Spec from Sujon's own Drive guide (Master Award Web Design System, section 6.1: radius pull 0.28, label 0.14, entry-point fill, label slot roll).
  • Technique seen on many award sites, for example Lusion and landonorris.com by OFF+BRAND. Written from scratch; no code copied.

OptionDefaultWhat it does
data-strength0.28How far the button follows the pointer (0 = no pull, fill and roll only).
data-radius80Extra px around the button where the pull starts, so it leans toward you before contact.
data-labelbutton textLabel text when the button has only an icon (it also becomes the rolled label).
.mb--outline / --round / --smallVariants. Colours come from --mb-bg, --mb-fg, --mb-fill, --mb-fill-fg.
label (JS)0.5Label parallax as a share of the button move (the Drive spec: 0.28 button, 0.14 label).
stiffness / damping (JS)0.14 / 0.72Spring feel. Higher stiffness snaps faster; lower damping wobbles more.
