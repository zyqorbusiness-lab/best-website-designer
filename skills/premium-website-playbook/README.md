# premium-website-playbook

The master skill: from brief to award-level website in 20 steps, naming which of the 24 skills to open at each step, the command to run and the gate to pass.

- `SKILL.md`: the route, the 24 skills by job, step-by-step guidance, decision rules, the 5-line token summary, the working loop, tier table, real mistakes, checklist.
- `scripts/route.mjs`: `node scripts/route.mjs --tier premium --3d --video` prints the route; `--json` for machines; `--lint <repo root>` checks all 24 skills exist and are linked.
- `examples/index.html`: route planner page (serve the repo with any static server).
- `examples/brief.example.json`: a filled brief.
