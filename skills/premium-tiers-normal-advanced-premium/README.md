# premium-tiers-normal-advanced-premium

What separates NORMAL ($300), ADVANCED ($1k) and PREMIUM ($10k) websites: features, techniques, weight budgets, frame-rate targets, time, red flags and the 8-dimension scorecard that decides quality.

- `SKILL.md`: the method.
- `scripts/tier-check.mjs`: `node scripts/tier-check.mjs path/to/site --tier advanced` (exit 1 on red flags or a failed gate).
- `examples/scorecard.md`, `examples/brief-tiers.md`: review and brief templates.
