# layout-grid-spacing

Premium layout without templates: 14 named page structures, spatial tokens, an 8-point spacing scale, a 12-column grid with subgrid, hairline ledgers instead of cards, sticky split narratives, pinned horizontal tracks, stacked sticky cards, the nav pill and finale footer, whitespace by brand type, breakpoints and phone re-composition.

- `SKILL.md`: the method.
- `scripts/layout-audit.js`: run `layoutAudit()` in any page for overflow culprits, tap targets, line length and distinct spacing values.
- `examples/index.html`: working demo (uses the OFL fonts from `../typography-premium/examples/fonts/`; falls back to system fonts if you copy this folder alone). Press G for the grid overlay.
