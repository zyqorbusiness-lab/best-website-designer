# copywriting-for-premium-sites

Specific, short, true website copy: interview and facts sheet, voice brief, eyebrow/title/body/proof/CTA numbers, headline formulas, honest proof, microcopy for every state, a banned list with replacements.

- `SKILL.md`: the method, rules with reasons, templates, tiers, what the linter found on the portfolio, checklist.
- `scripts/copy-lint.mjs`: `node scripts/copy-lint.mjs ./site` (exit 1 on errors). Also an ES module.
- `examples/index.html`: before/after copy desk with live linting.

MIT. Sources in `CREDITS.md`.
