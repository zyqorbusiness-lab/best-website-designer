# interactive-product-configurator

Drag-to-build and customise-your-product experiences: the anatomy (from a pizza-builder reel by @online.by.annie), real photo layers cut from CC0 photos, pointer-event drag with a snap ring, tap-to-add on phones, spaced placement and layer order, the live ticket, the finish (bake) transition, honest ordering, accessibility for drag, and an interaction QA script.

- `SKILL.md`: the method.
- `examples/index.html`: a compact working builder on real photo layers (loaded from `site/library/p/P041/img/` in this repo), with self-tests.
- Full concept: `site/library/p/P041/` (Hotcoal Kitchen).
