# Kit packaging and handoff (learned on Zyqor Motion Kit v5.2 -> v5.3, Nov 4 2026)

What went wrong in v5.2 and what fixed it in v5.3:

1. **Rules coverage table first.** List every rule the user ever gave (v5.3 had 49: EffectCraft-style text, never Blender for text,
   kinetic captions, premium sfx, glow off, gradient highlights, textured backgrounds, no purple/violet/cyan, Pinterest files used
   directly with the pin URL logged, make it unique >= 3 changes, 90 % title-safe, 1080x1920, -14 LUFS, WhatsApp <= 16 MB, study at
   60 fps...). One row each: where it lives (PDF page / prompt / checklist box / QC check). A row with no home = a bug.
   Slimming is allowed for code and media, not for rule text.
2. **Keep the tick checklist and the honesty rule in the kit** (concepts labelled as concepts; no fake clients, reviews or results;
   third-party media stays in the project folder). If the user said "no licence lectures", the checklist logs the source link
   instead of adding a licence box.
3. **Filled examples beat empty templates.** Ship a filled breakdown per reference and say how it was viewed.
4. **Sizes.** Zip <= 10 MB, PDF <= 2 MB (v5.3: 2.7 MB / 1.5 MB, 17 pages). Heavy things (frames, sheets, audio, video) are
   regenerated by scripts (`get_audio.sh`, `ref_breakdown.py`, `pin_download.py`), never zipped.
5. **Clean-unzip test, every time**, in a fresh directory: `--help` on every script, a dry run of the main builder, the QC gate on
   the demo spec, `check` on every shipped data folder, `bash -n` on shell scripts, `pip install --dry-run -r requirements.txt`,
   a real run of the downloader, `grep -rI '/home/'` on shipped scripts. Fix what breaks (v5.3: demo spec pointed at missing
   files, voice file was private, requirements listed packages no shipped script used, one script hard-imported a box-only helper).
6. **Box-only scripts say so** on line 1 and exit with a clear code and message elsewhere (dynamic import), they are not a silent
   failure in a stranger's folder.
7. **Exact claims.** "Reviewed" / "viewed" / "live" each get their real meaning in one sentence (cover seen, audio not heard;
   2 fps sample, 60 fps measured; 66 of 66 tutorial links 200, pins only sampled). Never "all links work" without a check.
8. **Render and look at the PDF pages** (pdftoppm at low dpi, montage) - overflow pages, tiny text and banned colours in the
   design show up there. Page size 6x10.67 in (phone), fonts embedded, no purple/violet/cyan in the design itself.
9. **Repo hygiene.** Push only text/code; run `node tools/credits-check.mjs --allow-flagged`; never touch `site/assets/hero/*`,
   `config-desktop.js` or `m/config-mobile.js`; commit by git-data API with `base_tree` so other people's files stay.
