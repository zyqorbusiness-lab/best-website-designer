The recipe

Three commands. The optimiser refuses settings that would visibly change the model, and the checker proves it with numbers and side-by-side crops.

  1. Install

    glTF Transform, meshoptimizer and sharp. Add KTX-Software only if you want KTX2.

    npm i @gltf-transform/core @gltf-transform/extensions \
  @gltf-transform/functions meshoptimizer sharp

  2. Optimise

    Before and after size, triangles, every texture, a budget, and a validator pass.

    node optimise.mjs helmet.gltf helmet.glb \
  --budget 14MB

  3. Verify

    Desktop and 390 px renders, close-up crops, PSNR and a pass or fail verdict.

    node verify.mjs helmet.gltf helmet.glb \
  --out verify/
  • Never simplify. Triangle cuts wrinkled the v3 car body. Keep every triangle.
  • Normal maps are never lossy. Lossy WebP bends them up to 17 degrees. Near-lossless or UASTC only.
  • Textures at least as big as the screen. A hero model on a phone covers about 780 device pixels, so 2048 stays 2048.
  • meshopt at 16 / 12 / 14 bits. Position, normal and UV. Below 10-bit normals the highlights band.
  • One file for both builds. The phone gets the same GLB and HDRI. Only the pixel ratio is capped at 2.
  • Lazy and idle. Load near the viewport, render only when something moves, pause off-screen.
