# motion-and-scroll-storytelling

Motion that reads as designed: tokens (durations, three curves), reveal timings Sujon chose, GSAP ScrollTrigger + Lenis scroll stories (pins, scrubbed timelines, horizontal tracks), CSS scroll-driven animations, scroll-scrubbed video with every scroll-world engine rule, page transitions, reduced motion and the motion review.

- `SKILL.md`: the method.
- `examples/index.html`: tested demo (pinned vendor files in `examples/vendor/`).
