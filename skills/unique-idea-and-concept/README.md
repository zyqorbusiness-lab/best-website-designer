# unique-idea-and-concept

Find the one big idea a site is built around ("[product] as [thing or place]"), then turn it into a metaphor, a story arc, chapters, a camera grammar and a brief before design starts.

- `SKILL.md`: the method.
- `scripts/storyboard.mjs`: `--check "<idea sentence>"` (exit 1 on fail) and `--idea ... --category ... --chapters 4-6` for a storyboard skeleton.
- `examples/storyboards.md`: three worked storyboards (NORMAL, ADVANCED, PREMIUM).
- Generator tools live in the sibling skill `../unique-concepts/`.
