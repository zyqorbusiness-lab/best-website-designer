# Idea sources

No text, code or assets were copied from these; they are the methods this skill builds on, credited because the
ideas are theirs.

| idea | source | used in |
|---|---|---|

| Constraint cards drawn at random | Brian Eno & Peter Schmidt, *Oblique Strategies* (1975), https://en.wikipedia.org/wiki/Oblique_Strategies | section 2, `tools/constraint-cards.mjs` (our own cards, written for web concepts) |
| Steal from many, credit, transform | Austin Kleon, *Steal Like an Artist* (2012), https://austinkleon.com/steal/ | section 4 |
| Substitute / combine / adapt / reverse prompts behind category inversion | SCAMPER, Bob Eberle (1971), after Alex Osborn's idea-spurring questions, https://en.wikipedia.org/wiki/SCAMPER | section 3 |
| Scroll-scrubbed single camera move ("scroll-world") | *scroll-world* skill by cyw (MIT), adapted in the Zyqor Studio portfolio intro | section 5 |
| Contrast thresholds | W3C WCAG 2.x, relative luminance and contrast ratio, https://www.w3.org/TR/WCAG21/#contrast-minimum | section 8, `tools/palette-check.mjs` |
| 14 named page structures, "never hero + 3 cards" | Sujon Hoque, Zyqor Studio *Master Award Web Design System* (own work) | sections 6-7 |
