# typography-premium

Premium web type without guessing: pairing (display + body + mono for data), a fluid clamp() scale, tracking and leading by size, craft details, loading without layout shift, and font licensing (OFL vs Fontshare FFL vs paid).

- `SKILL.md`: the method, tables, code, tiers, checklist.
- `scripts/type-scale.mjs`: `node scripts/type-scale.mjs --css` prints the scale; `--check "clamp(...)"` prints px at 6 widths.
- `examples/index.html`: tested specimen (serve with any static server).
- `examples/fonts/`: four OFL families, each with a `.credit.json`.

MIT for code and text. Fonts keep their SIL OFL 1.1 licence (see `CREDITS.md`).
