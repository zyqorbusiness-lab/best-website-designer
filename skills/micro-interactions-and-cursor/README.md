# micro-interactions-and-cursor

The small interactions that make a site feel crafted: a state matrix for every control, magnetic button, lerp cursor with labels, border light and tilt, press feedback, squish toggle, odometer (real numbers only), accordion physics, real-action toasts, opt-in sound, honest form states, skeletons, and a touch version of every pointer effect.

- `SKILL.md`: the method with specs and code.
- `examples/index.html`: every pattern, tested (self-tests for dead buttons, href="#", 44px targets, ARIA states).
- Production components: `../../site/components/`.
