# threejs-3d-premium

Premium three.js 3D: real models (sourcing, licences, optimisation), ACES/AgX renderer defaults, HDRI + key/rim lighting, PBR materials that look real, contact shadows, bounding-sphere framing for desktop and portrait phones, scroll camera beats, the finish studio, render-on-demand, pausing and the no-WebGL poster.

- `SKILL.md`: the method.
- `examples/index.html`: tested stage (runs inside this repo: loads three.js r170 from `site/vendor/three/`, the CC0 vase from `site/library/_assets/models/` and the CC0 studio HDRI from `site/assets/hdri/`). To use it elsewhere, install `three@0.170` and download the same CC0 assets from Poly Haven.
